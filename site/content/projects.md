## C언어 기반 편의점 POS프로그램
리눅스프로그래밍 수업에서 C언어로 제작한 개인 프로젝트입니다. 편의점의 재고 관리, 상품 판매, 결제 금액 계산 등의 기능을 구현하며 수업에서 배운 내용을 실제 프로그램으로 연결했습니다.

## 프로젝트 개요
- 수행 시기 : 2학년 2학기 리눅스프로그래밍 수강 중
- 개발 언어 : C
- 개발 환경 및 도구 : Linux, Vim
- 구현 범위 : 재고 조회·추가, 상품 판매, 금액 계산, 예외 처리

## 프로젝트 목적
리눅스프로그래밍 수업에서 배운 내용을 바탕으로 Linux 환경에서 Vim을 사용해 프로그램을 작성하는 과정을 익히고자 했습니다. C언어로 편의점 POS 기능을 구현하면서 Linux 환경과 Vim 사용에 익숙해지고 수업에서 학습한 내용을 실제 프로그램 제작에 적용하는 것을 목표로 했습니다.

## 주요 구현 기능
- 재고 조회 : 현재 등록된 상품의 재고를 확인하는 기능
- 재고 추가 : 상품의 재고를 추가하는 기능
- 상품 판매 : 상품 판매를 처리하는 기능
- 금액 계산 : 판매 과정에서 필요한 금액을 계산하는 기능
- 예외 처리 : 잘못된 입력이나 처리하기 어려운 상황에 대응하는 기능
개인 프로젝트로 진행했으며, 위 기능을 직접 구현했습니다.

## 수행 과정과 도구 활용
리눅스프로그래밍 수업의 개발 환경에 맞춰 Linux에서 Vim을 사용해 C언어 코드를 작성했습니다. 편의점 POS 프로그램에 필요한 재고 관리, 상품 판매, 금액 계산 등의 기능을 구현하며, 수업에서 배운 내용을 실제 프로그램에 적용했습니다.

개발 과정에서는 POS 기능을 구현하는 것과 함께 Linux 환경에서 코드를 작성하고 수정하는 방식에도 익숙해지고자 했습니다. 특히 Vim을 사용해 프로그램을 제작하면서 편집기 사용법을 익히고, 이를 실제 코드 작성에 활용하는 경험을 쌓았습니다.

혼자 해결하기 어려운 오류가 발생했을 때는 당시 상황과 오류 내용을 AI에 설명하고, 원인이 무엇인지 질문했습니다. 코드를 직접 받는 대신 원인에 대한 설명을 참고해 문제를 이해하고, 해결 방법은 스스로 생각하며 코드를 수정했습니다.
